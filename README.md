# ✂️ Tailor Shop Field Project

## 📌 Project Overview

This project was conducted as an independent field project to understand and solve a real-world problem faced by a tailor shop using data.

The project started with collecting field-level data from a tailor shop. The collected data was then cleaned, analysed and used to identify patterns in customer orders, pricing, payments, delivery and tailoring-related activities.

The project demonstrates an end-to-end data science workflow — from **identifying a real-world problem and collecting data to analysing the data, applying machine learning and generating useful business insights.**

## ❗ Problem Identified

A tailor shop handles many customer orders with different garment types, fabrics, quantities, prices, alterations, delivery dates and payment details.

When this information is managed manually, it can be difficult for the shop to clearly understand:

- Which garments and fabrics are most popular
- Which orders generate higher revenue
- How order quantity affects the total order value
- How alterations affect the final price
- Which payment methods and payment statuses are common
- How delivery time varies between orders
- How customer ratings relate to the service provided
- Which factors are important when predicting the value of an order

Because the shop has a large amount of order information, analysing it manually can make it difficult to identify useful patterns and make data-driven decisions.

### 🎯 Problem Statement

**The main problem was to use collected tailor shop data to understand customer and order patterns, identify factors affecting order value, and develop data-driven insights that could help improve business decision-making.**

## 💡 Solution

To solve this problem, I collected and organised the required field data and converted it into a structured dataset.

I then used Python and data science techniques to:

1. Clean and prepare the data.
2. Perform exploratory data analysis.
3. Create visualisations to understand important patterns.
4. Analyse customer, garment, fabric, pricing and payment information.
5. Apply feature engineering where required.
6. Build machine learning models.
7. Evaluate the models using suitable performance metrics.
8. Use the results to generate practical business insights.

This approach transformed raw field data into meaningful information that can support better decision-making for a tailor shop.
